# Stash — Android (Firebase Remote Config)

## Быстрый запуск на GitHub
1. В консоли Firebase создайте/откройте проект для **Stash**, импортируйте ваш шаблон Remote Config (`Publish from a file`).
2. Зарегистрируйте Android-приложение с пакетом **`app.stash`** и скачайте **`google-services.json`**.
3. Положите **`google-services.json`** в папку `mobile/app/` (рядом с `mobile/app/build.gradle.kts`).
4. Загрузите все файлы репозитория на GitHub — в разделе **Actions** автоматически соберется `app-debug.apk`.
